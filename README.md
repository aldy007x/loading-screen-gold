## Entry

> Loading… while your AI agent confidently rewrites the code you wrote an hour ago — faster, cleaner, and wrong in a brand-new way. Read the diff before you merge it.

## Run

```sh
python3 main.py
```

Writes the tip to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR`
(defaults to `output`). The program self-checks that the entry is exactly one
non-blank line of 1–200 characters and exits non-zero otherwise.
